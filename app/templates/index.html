Sample AI app behind Entra ID

Users sign in with the customer's Microsoft Entra ID. Every API call carries an Entra access token, which the server validates (RS256 signature against the tenant's keys, issuer, audience, tenant, expiry, scope). The token's roles claim decides which data collections the user may read, and only those rows ever reach the model.
